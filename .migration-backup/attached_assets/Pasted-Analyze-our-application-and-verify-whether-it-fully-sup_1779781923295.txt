Analyze our application and verify whether it fully supports the following AI-powered Expo CRM workflow and requirements.

Product Goal:
Our application is an AI-powered Expo CRM and Meeting Intelligence platform where users can:

* Record expo/business discussions
* Scan visitor ID cards, QR codes, badges, or business cards
* Automatically fetch company and contact person details
* Save transcripts linked to those contacts and companies
* Manage leads and follow-ups inside the application

Please check the application architecture, backend, frontend, APIs, database structure, UI flow, and feature implementation against these requirements.

Core Workflow:
User attends expo
→ Starts meeting recording
→ Scans QR/business card/ID badge
→ OCR extracts company + person details
→ AI structures extracted information
→ Transcript is generated and linked
→ Data saved automatically in CRM
→ User can manage leads later
