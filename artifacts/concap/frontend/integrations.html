HubSpot

Sync contacts, companies, notes, and deals.
Checking…
Connect your own HubSpot portal. Concap no longer uses a shared HubSpot account — each workspace syncs into its own portal. An owner or admin can connect it below so your conversations land in your CRM, isolated from every other workspace.

Connect your HubSpot account in one click. You'll be sent to HubSpot to approve access, then brought right back here. Concap requests only the CRM scopes it needs:

crm.objects.contacts.read   crm.objects.contacts.write
crm.objects.companies.read   crm.objects.companies.write
crm.objects.deals.read   crm.objects.deals.write
crm.schemas.contacts.read   crm.schemas.companies.read   crm.schemas.deals.read
crm.objects.owners.read   oauth
HubSpot connection isn't set up on this server yet. An administrator needs to configure the HubSpot OAuth app (HUBSPOT_CLIENT_ID, HUBSPOT_CLIENT_SECRET, PUBLIC_BASE_URL) before you can connect.

We never see your HubSpot password. Access is granted by OAuth and you can revoke it at any time from HubSpot's connected-apps settings or by clicking Disconnect here.

Sync behavior

What gets synced

Fine-tune which parts of each conversation are pushed to HubSpot.

Pick the HubSpot user that follow-up tasks are routed to.

Only an owner or admin can change these settings.

  • Dedup: Contacts are matched by email then phone. Companies are matched by domain then name. Re-syncing updates the existing record instead of creating duplicates.
  • Idempotent: Tasks and notes are tracked per conversation, so re-syncing adds only newly-found action items instead of duplicating existing ones.

Sync behavior

Only an owner or admin can change these settings.

  • Dedup: Contacts are matched by email then phone. Accounts are matched by domain then name. Re-syncing updates the existing record instead of creating duplicates.
  • Notes: The full transcript, AI summary, intent, pain points, action items, and key quotes are attached as a Salesforce note on the contact.

Connect your own Plaud account in one click. You'll approve access on Plaud, then come right back. Read your existing transcripts and summaries here in Concap—no mobile companion needed. Each user connects their own Plaud account. Imported recordings are also visible within your site workspace.

Plaud isn't set up on this server yet. An administrator needs to configure PUBLIC_BASE_URL before you can connect. Account authorization registers automatically when supported by Plaud. Embedded Developer Portal keys are separate and are not needed here.

We never see your Plaud password. Access is granted by OAuth and you can disconnect at any time.

  • What syncs: Each recording's transcript and Plaud's AI summary appear on this site in Conversations and Meeting Intelligence.
  • Dedup: Recordings already imported are skipped, so syncing again only pulls new ones.
